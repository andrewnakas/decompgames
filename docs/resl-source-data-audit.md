The top-level upstream `resources/` directory is excluded from the private build; only generated external files are embedded. A source-wide search for static byte arrays found the SDL cursor outside `src/game/resources`; other matches reviewed so far were control, text, audio, or rendering logic. Re-run this audit after source changes and before distribution. Do not infer that an exhaustive asset clearance has already happened.

A September 23 follow-up inspected the remaining small tables in the pinned `src/game/resources` directory. `rail_connection_bias`, `rail_connection_rule`, and `rail_type_meta` map rail ports, neighbors, and signal rules; they do not encode pictures or level placement. `movement_paths` contains per-rail motion coordinates used by routing and collision checks. `carriage_bias` and `semaphore_glyph_bias` are sprite-alignment offsets coupled to the new drawings. These tables are retained as GPL engine geometry, not claimed as independently authored art. Their alignment and visual effects still need broader dynamic checks; this classification does not clear the whole source tree.

The private build recipe now compares the entire pinned `src/game/resources/*.cpp` inventory with explicit sets of ten independently replaced glyph tables, five independently replaced scenario tables, and six retained engine-geometry tables. It fails if an unclassified table appears and records sizes and SHA-256 hashes for the retained six. This is a reproducible inventory guard; it does not substitute for a whole-source provenance review. `carriage_bias` and `semaphore_glyph_bias` encode sprite-alignment offsets recovered from the original game. Replacing them from the new sprite geometry is preferable before a strict replacement-asset release.

The source copy used for the browser build is now allowlisted to `src/`, `CMakeLists.txt`, `LICENSE`, and `README.md`; it omits the upstream top-level original game data, Android/iOS launcher art, and executable-extraction utilities under `src/game/resources/scripts` and `utility`. Only generated `resources/open-junction` files are added back. The narrowed copy compiled and its archive inventory passed in [private CI run 35903723403](https://github.com/andrewnakas/decompgames/actions/runs/35903723403). Final whole-source provenance review remains open.

`scripts/package-open-junction-private-source.py` now checks the build-record hashes, the allowlisted source roots, and the generated-resource boundary before creating a deterministic private source archive. The CI job checks that the patched text source and generated `play.7` are present. It neither uploads this archive nor distributes the runtime; this packages evidence for review without claiming the remaining asset audit is complete.

The first gameplay screenshot also exposed an inherited original-game footer and a grass routine that scattered original-style presentation pixels. The private recipe now substitutes an Open Junction source credit, uses a clear drafted grid, and retains the independently generated trees and houses. The updated frame is legible at the intended 640×480 SDL size; tree density and numeric counters still need review. The screenshot artifact is temporary and contains no engine binary.

The candidate build is still private. Muted browser tests establish menu input, entry to the gameplay loop, one committed player rail, a second station appearing with game time, train dispatch, movement, and one successful train delivery through the engine's completion branch. The independently drafted scenario starts with three connecting rails between the first two stations. A private browser Save, page reload, and Archive restore passed using the engine's IDBFS mount. The actual shared player passed export/delete/import controls and resumed its saved two-station game through Archive in an ephemeral preview. A trace-only probe reached the year-2000 level-transition branch and reset to year 1800 at level 2; it does not establish continuous play through 200 years. Release still requires wider visual review, scenario/game-over coverage, and final provenance review. It remains outside the five-release count.
