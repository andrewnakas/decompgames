# Release gates

- [ ] Eight complete instant-play titles pass input, audio, representative play, save and reload tests.
- [ ] Doom and Quake local import pass valid/invalid data, cancellation, privacy, and save tests.
- [ ] Thirty entries have verified project links, license records, and substantive individual guidance.
- [ ] Every published runtime has checksums, corresponding source archive, patches, toolchain and notices.
- [ ] IndexedDB isolation, save backups, deletion, storage failure, and upgrades tested.
- [ ] Responsive layout, keyboard access, metadata, canonical URLs, sitemap and internal links checked.
- [ ] Runtime/storage endpoints support required MIME types, CORS, cache and range behavior.
- [ ] GitHub source and CI published; prior releases retained for rollback.
- [ ] Production domains and HTTPS verified; player origin is isolated from discovery.
- [ ] Search Console and Bing verification completed; sitemap submitted.

## Operational rhythm

Weekly: review hosting spend and broken launches. Keep initial operating spend below $50/month.

Monthly: inspect organic clicks, indexed pages, relevant search queries, successful starts, repeat visits, and verified catalog coverage. Improve pages receiving relevant impressions before expanding unrelated content.

Community release notes and demonstrations are drafts until explicitly authorized for posting. ExeBrowser crosslinks should point to working, distinct game guides.
