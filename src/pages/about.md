Decomp Games helps you find the projects giving classic games another life. It comes from the creator of [ExeBrowser](https://exebrowser.com/), with a narrower focus: the source projects, browser integrations, and practical details behind each game.

## Open source

The [website source and catalog](https://github.com/andrewnakas/decompgames) are public. New platform code uses GPL-2.0-or-later. Engines keep their upstream licenses. Redistributable freeware data can have separate terms; “playable for free” and “open-source assets” are different claims.

## Built on other people’s hard work

The upstream maintainers made these projects possible. Every entry links to its source. Support those projects, report reproducible bugs, and keep their notices intact when sharing builds.

## A useful collection, honestly described

We distinguish decompilations from related source ports and recreations. We show actual catalog counts and specific test records. The aim is a large, dependable collection; we do not claim to include every game or to be the largest without evidence.

There are no accounts, comments, public file uploads, or cloud saves in this version. Finding a game and getting it running comes first.
