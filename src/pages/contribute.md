The most useful contribution is a precise one. [Open an issue or pull request](https://github.com/andrewnakas/decompgames) with the source project and what you have verified.

## Suggest a project

Include the game title, canonical upstream repository, project category, engine license, required assets, and a working build link if one exists. A directory entry does not need a browser build. It does need trustworthy sources.

## Test an integration

Record your browser and operating system, runtime revision, controls tried, audio result, save/reload result, and a short description of actual gameplay. A screenshot of the title screen is a startup report, not a playthrough.

## Improve the platform

The repository contains the catalog, website, runtime recipes, and validation scripts. Read its contribution guide before changing an entry’s availability. New binaries need pinned sources, retained license notices, and a matching manifest.
