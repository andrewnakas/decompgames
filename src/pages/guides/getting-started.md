Pick a game from the [catalog](/games/). Its page explains the engine, required files, controls, and what has actually been tested.

## Four ways to explore

- **Play now** includes redistributable game data with the browser integration.
- **Play with your files** needs data from a copy you already have. The engine loads selected files locally.
- **Play demo** means limited content, even if the engine itself is complete.
- **View project** takes you to an upstream project. It does not promise a browser version here.

## Before starting

Use a keyboard and mouse for the desktop games in this first collection. Check the game’s test record before assuming touch or a controller will work. Click Start to download its engine and data; merely browsing the catalog does not load a game.

Most engines capture keyboard input when the game has focus. Click the canvas if controls stop responding. Escape usually opens the game menu or releases pointer lock. Browser fullscreen can also be exited with Escape.

## Keep a copy of your saves

Save inside the game first, then export a backup from the player. A browser download is your portable copy; keeping a tab open is not a backup. Browser storage can disappear after clearing site data, using private browsing, or running low on disk space.

## Something went wrong?

Record the game, browser version, displayed error, and what you did immediately before it happened. [Report an issue](https://github.com/andrewnakas/decompgames/issues) without attaching copyrighted game files or private saves.
